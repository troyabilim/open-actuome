# Contributing

OpenActuome is an experimental proposal owned by Troya Science. Contributions
are welcome under the repository's MIT license; do not submit material you lack
the right to share. External contribution or adoption is not yet claimed.

Useful first contributions:

1. Identify an ambiguous field and propose a measurable definition.
2. Supply a profile with source evidence and clearly stated conditions.
3. Add a failure case that the validator should reject.
4. Describe a real workflow and the smallest useful integration.

Run `python -m unittest discover -s tests -v` and validate every changed example.
Label simulation, synthetic and manufacturer-declared values accurately. Keep
unknown fields null. Do not fabricate competitive rankings or claim a safety
certification from a schema check. Discuss breaking schema changes before coding.

No contributor is asked to contact manufacturers, publish private specifications
or conduct unsafe tests. Documentation and code may be improved without hardware.
