# Roadmap and release status

## Implemented in this package

- Experimental schema with units, evidence labels and explicit coverage.
- Dependency-free version-specific validator with semantic checks.
- Synthetic complete/partial profiles and an unknown-value template.
- Profile-to-Markdown reporting tool and automated regression tests.
- Measurement protocol, unscored index template, bilingual manifesto.

## Next empirical milestone

Obtain permission to publish measurements from two different actuators. Apply
the protocol, publish source evidence, and obtain an independent review.

## Interoperability milestone

Build one version-pinned adapter for supported fields, test round-trip fidelity,
and document non-representable properties. Choose its target after feedback from
an actual engineering user. Do not claim controller or simulator support in advance.

## Research milestone

Only after usable measurements exist, investigate whether shared profiles reduce
configuration effort or improve adaptation. Predefine baselines and outcomes.

## Publication status

Code and documentation belong in [https://github.com/troyabilim/open-actuome](https://github.com/troyabilim/open-actuome).
The draft has not been submitted to arXiv. Measured profiles, independent review
and named human research contributions are required before academic submission.
